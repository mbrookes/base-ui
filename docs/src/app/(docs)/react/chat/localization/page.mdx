# Localization

<Subtitle>
  Translate all built-in labels, announcements, and dynamic strings by overriding the locale text
  object.
</Subtitle>
<Meta
  name="description"
  content="Translate Base UI Chat labels and announcements by passing a localeText object to Chat.Root."
/>

All user-visible strings in Base UI Chat are centralized in a `ChatLocaleText` object.
The defaults are English.
Pass a partial or full override to `Chat.Root` (or `ChatProvider`) to translate or customize any string.

## Basic usage

Pass `localeText` to `Chat.Root`:

```tsx
import { Chat } from '@base-ui/chat/chat';

<Chat.Root
  adapter={adapter}
  localeText={{
    composerInputPlaceholder: 'Schreib eine Nachricht…',
    composerSendButtonLabel: 'Senden',
    scrollToBottomLabel: 'Nach unten scrollen',
    threadNoMessagesLabel: 'Noch keine Nachrichten',
    threadNoMessagesHelperText: 'Schreib eine Nachricht, um zu beginnen',
  }}
>
  {/* … */}
</Chat.Root>;
```

`localeText` is merged with the defaults — only the keys you provide are overridden.

## Dynamic strings

Keys that accept arguments are typed as functions.
Pass a function that accepts the same arguments and returns a localized string:

```tsx
<Chat.Root
  adapter={adapter}
  localeText={{
    typingIndicatorLabel: (users) => {
      const names = users.map((u) => u.displayName ?? u.id).join(', ');
      return users.length === 1 ? `${names} schreibt…` : `${names} schreiben…`;
    },
    conversationTimestampAriaLabel: (dateTime) =>
      new Date(dateTime).toLocaleString('de-DE', {
        weekday: 'long',
        year: 'numeric',
        month: 'long',
        day: 'numeric',
        hour: '2-digit',
        minute: '2-digit',
      }),
    composerRemoveAttachmentLabel: (fileName) => `${fileName} entfernen`,
  }}
>
  {/* … */}
</Chat.Root>
```

## TypeScript

The `ChatLocaleText` type is exported for use in your own locale objects:

```tsx
import type { ChatLocaleText } from '@base-ui/chat/chat';

const deLocale: Partial<ChatLocaleText> = {
  composerInputPlaceholder: 'Schreib eine Nachricht…',
  composerSendButtonLabel: 'Senden',
};

<Chat.Root adapter={adapter} localeText={deLocale}>
  {/* … */}
</Chat.Root>;
```
