## Usage guidelines

- **File Upload is headless**: Use File Upload to build custom file selection and upload experiences with full control over the UI. Base UI provides the state management and accessibility, you build the UI.
- **No built-in upload**: File Upload handles file selection and validation, but does not include upload functionality. You control how and where files are uploaded using callbacks and state.
- **Ideal for custom workflows**: Perfect for applications that need specific upload flows, preview displays, validation feedback, or integration with custom upload services.
- **Form controls must have an accessible name**: Ensure file upload dropzones and triggers are properly labeled. Use the [`Field` component](/react/components/field) or native `<label>` elements for accessibility.

## Anatomy

File Upload is composed of several subcomponents that work together. Import them and assemble:

```jsx title="Anatomy"
import { FileUpload } from '@base-ui/react/file-upload';

<FileUpload.Root>
  <FileUpload.Input />
  <FileUpload.Dropzone>Drag files here or click</FileUpload.Dropzone>
  <FileUpload.Trigger>Upload</FileUpload.Trigger>
  <FileUpload.PreviewList>
    <FileUpload.PreviewItem>{/* preview content */}</FileUpload.PreviewItem>
  </FileUpload.PreviewList>
</FileUpload.Root>;
```

## Examples

### Basic setup

<DemoFileUploadMinimal />

`FileUpload.Root` manages file state and provides context to child components. It accepts files through drag-and-drop, click-to-select, paste, or the hidden input element.

```jsx title="Basic file upload"
import { FileUpload } from '@base-ui/react/file-upload';

function FileList() {
  const { files, removeFile } = FileUpload.useFileUploadContext();
  return files.map((file) => (
    <div key={file.id}>
      {file.name}
      <button onClick={() => removeFile(file.id)}>Remove</button>
    </div>
  ));
}

export default function App() {
  return (
    <FileUpload.Root maxFiles={5}>
      <FileUpload.Input />
      <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
      <FileUpload.Trigger />
      <FileList />
    </FileUpload.Root>
  );
}
```

### Controlled state

Control file state using `onFilesChange` callback:

```jsx title="Handling file changes" "onFilesChange"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

export default function App() {
  const [files, setFiles] = React.useState([]);

  return (
    <FileUpload.Root
      onFilesChange={(newFiles) => {
        setFiles(newFiles);
      }}
    >
      <FileUpload.Input />
      <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
      <FileUpload.Trigger>Select files</FileUpload.Trigger>
    </FileUpload.Root>
  );
}
```

## Usage

### File validation

<DemoFileUploadValidation />

Control which files are accepted using `accept`, `maxSize`, `minSize`, and `maxFiles` props:

```jsx title="File validation" "accept" "maxSize" "maxFiles"
<FileUpload.Root
  accept="image/png, image/jpeg, .pdf"
  maxSize={10 * 1024 * 1024}
  minSize={1024}
  maxFiles={5}
  onFileReject={(file, reason) => console.log(`Rejected: ${reason}`)}
>
  <FileUpload.Input />
  <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
  <FileUpload.Trigger />
</FileUpload.Root>
```

**Notes**

- `accept` mirrors the native file input: use MIME types like `image/png` or file extensions like `.png`.
- For image previews, always provide meaningful `alt` text on preview images for screen reader users.
- File size limits are in bytes. The example above limits files to 10MB and a minimum of 1KB.

### Drag and drop state

Access the dragging state in the Dropzone render prop:

```jsx title="Dragging state" "{isDragging}"
<FileUpload.Dropzone>
  {({ isDragging }) => (
    <div style={{ opacity: isDragging ? 0.5 : 1 }}>
      {isDragging ? 'Drop files here' : 'Drag files or click'}
    </div>
  )}
</FileUpload.Dropzone>
```

### Handling file dialog cancellation

Use `onCancel` to react when the user closes the file dialog without selecting files:

```jsx title="Handle cancel" "onCancel"
<FileUpload.Root onCancel={() => console.log('User canceled file selection')}>
  <FileUpload.Input />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>
```

### Detecting duplicate files

Use `onDuplicateFile` to detect when a user selects the same file more than once. Duplicates are ignored by default:

```jsx title="Duplicate detection" "onDuplicateFile"
<FileUpload.Root onDuplicateFile={(file) => console.log('Duplicate:', file.name)}>
  <FileUpload.Input />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>
```

### Paste from clipboard

`FileUpload.Root` listens for paste events and includes any file-like clipboard items (screenshots, copied images). Paste is ignored when focused on an input, textarea, or contenteditable element:

```jsx title="Paste files"
<FileUpload.Root>
  <FileUpload.Input />
  <FileUpload.Dropzone>Paste or drop files here</FileUpload.Dropzone>
</FileUpload.Root>
```

### Folder upload

Enable directory selection with the `directory` prop. This uses `webkitdirectory` under the hood, so browser support varies:

```jsx title="Folder upload" "directory"
<FileUpload.Root directory>
  <FileUpload.Input />
  <FileUpload.Trigger>Select folder</FileUpload.Trigger>
</FileUpload.Root>
```

### Preview items with context

<DemoFileUploadImagePreview />

Use `FileUploadPreviewItem` and `useFileUploadPreviewItem` to display and manage file information:

```jsx title="File preview items" "useFileUploadPreviewItem"
import { FileUpload } from '@base-ui/react/file-upload';

function CustomPreviewItem({ file }) {
  const { onRemove } = FileUpload.useFileUploadPreviewItem();

  return (
    <div>
      {file.preview && <img src={file.preview} alt={file.name} />}
      <span>{file.name}</span>
      <button onClick={onRemove}>Remove</button>
    </div>
  );
}

export default function App() {
  const { files } = FileUpload.useFileUploadContext();

  return (
    <FileUpload.Root>
      <FileUpload.Input />
      <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
      <FileUpload.PreviewList>
        {files.map((file) => (
          <FileUpload.PreviewItem key={file.id} file={file}>
            <CustomPreviewItem file={file} />
          </FileUpload.PreviewItem>
        ))}
      </FileUpload.PreviewList>
    </FileUpload.Root>
  );
}
```

## Accessibility

File Upload is built with accessibility as a core feature:

- **WCAG 2.1 Level AA**: Compliant with Web Content Accessibility Guidelines
- **Keyboard navigation**: Full keyboard support with logical tab order
- **Screen reader support**: Semantic HTML and ARIA labels for VoiceOver, JAWS, and other assistants
- **Focus management**: Clear focus indicators and focus trapping in dialogs
- **Live regions**: File status updates announced to screen reader users

**Best practices:**

- Label your file upload UI with visible text or the [`Field` component](/react/components/field)
- Provide meaningful alt text for image previews
- Use ARIA labels on buttons and interactive elements
- Test with a screen reader during development
