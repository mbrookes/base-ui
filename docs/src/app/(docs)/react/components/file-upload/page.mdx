## Usage guidelines

- **File Upload is headless**: Use File Upload to build custom file selection and upload experiences with full control over the UI. Base UI provides the state management and accessibility, you build the UI.
- **No built-in upload**: File Upload handles file selection and validation only. **You must implement the actual file upload** using fetch, axios, or your HTTP client. See [Uploading Files](#uploading-files) below.
- **Ideal for custom workflows**: Perfect for applications that need specific upload flows, preview displays, validation feedback, or integration with custom upload services.
- **Form controls must have an accessible name**: Ensure file upload dropzones and triggers are properly labeled. Use the [`Field` component](/react/components/field) or native `<label>` elements for accessibility.

## Examples

### Basic setup

<DemoFileUploadMinimal />

`FileUpload.Root` manages file state and provides context to child components. It accepts files through drag-and-drop, click-to-select, paste, or the hidden input element.

```jsx title="Basic file upload"
import { FileUpload } from '@base-ui/react/file-upload';

function FileList() {
  const { files, removeFile } = FileUpload.useFileUploadContext();
  return files.map((file) => (
    <div key={file.id}>

      <button onClick={() => removeFile(file.id)}>Remove</button>
    </div>

export default function App() {
  return (
    <FileUpload.Root maxFiles={5}>
      <FileUpload.Input />
      <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
      <FileUpload.Trigger />
      <FileList />
    </FileUpload.Root>
  );
}
```

## Usage

### File validation

<DemoFileUploadValidation />

Control which files are accepted using `accept`, `maxSize`, `minSize`, and `maxFiles` props:

```jsx title="File validation" "accept" "maxSize" "maxFiles"
<FileUpload.Root
  accept="image/png, image/jpeg, .pdf"
  maxSize={10 * 1024 * 1024}
  minSize={1024}
  maxFiles={5}
  onFileReject={(file, reason) => console.log(`Rejected: ${reason}`)}
>
  <FileUpload.Input />
  <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>
  <FileUpload.Trigger />
</FileUpload.Root>
```

**Notes**

- `accept` mirrors the native file input: use MIME types like `image/png` or file extensions like `.png`.
- File extensions are matched against the file name (case-insensitive).
- For image previews, always provide meaningful `alt` text on preview images for screen reader users.
- File size limits are in bytes. The example above limits files to 10MB and a minimum of 1KB.

### Custom validation

Use `validator` for custom rules beyond size and type checks. Return an error message to reject the file:

```jsx title="Custom validation" "validator"
<FileUpload.Root
  validator={(file) => {

    return null;

  onFileReject={(file, reason) => console.log(`${file.name}: ${reason}`)}
>
  <FileUpload.Input />
  <FileUpload.Dropzone>Upload files</FileUpload.Dropzone>

</FileUpload.Root>
```

### Image validation

Use utility functions to validate image dimensions and detect actual file types:

```jsx title="Image dimension validation" "getImageDimensions"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';
import { getImageDimensions } from '@base-ui/utils/getImageDimensions';

export default function ImageUpload() {
  return (
    <FileUpload.Root
      accept="image/*"
      validator={async (file) => {
        const dimensions = await getImageDimensions(file);

        if (!dimensions) {
          return 'Unable to determine image dimensions';
        }

        if (dimensions.width < 800) {
          return `Image width must be at least 800px (current: ${dimensions.width}px)`;
        }

        if (dimensions.height < 600) {
          return `Image height must be at least 600px (current: ${dimensions.height}px)`;
        }

        return null;
      }}
    >
      <FileUpload.Input />
      <FileUpload.Dropzone>Drop images here</FileUpload.Dropzone>
      <FileUpload.Trigger>Select images</FileUpload.Trigger>
    </FileUpload.Root>
  );
}
```

**Available image utilities:**

- `getImageDimensions(file)` - Get width and height of an image
- `validateImageDimensions(file, constraints)` - Validate against min/max width/height
- `getImageAspectRatio(file)` - Calculate aspect ratio
- `detectFileType(file)` - Detect actual file type from magic numbers (more reliable than MIME type)
- `isValidFileType(file, acceptedTypes)` - Validate file type against accepted list

**Important: FileUpload handles file selection only. You must implement the actual upload.**

Here's a complete example showing how to upload files to your server:

```jsx title="Upload files with fetch" "FormData" "fetch"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

export default function FileUploadWithUpload() {
  const [isUploading, setIsUploading] = React.useState(false);
  const [uploadError, setUploadError] = (React.useState < string) | (null > null);
  const { files, removeFile } = FileUpload.useFileUploadContext();

  const handleUpload = async () => {
    setIsUploading(true);
    setUploadError(null);

    try {
      const formData = new FormData();
      files.forEach((file) => {
        formData.append('files', file);
      });

      const response = await fetch('/api/upload', {
        method: 'POST',
        body: formData,
      });

      if (!response.ok) {
        throw new Error('Upload failed');
      }

      // Clear files after successful upload
      files.forEach((file) => removeFile(file.id));
    } catch (error) {
      setUploadError(error instanceof Error ? error.message : 'Unknown error');
    } finally {
      setIsUploading(false);
    }
  };

  return (
    <FileUpload.Root>
      <FileUpload.Input />
      <FileUpload.Dropzone>Drop files here</FileUpload.Dropzone>
      <FileUpload.Trigger>Select files</FileUpload.Trigger>

      {files.length > 0 && (
        <>
          <button onClick={handleUpload} disabled={isUploading}>
            {isUploading ? 'Uploading...' : 'Upload Files'}
          </button>
          {uploadError && <div style={{ color: 'red' }}>{uploadError}</div>}
        </>
      )}

      <FileUpload.PreviewList>
        {files.map((file) => (
          <FileUpload.PreviewItem key={file.id} file={file}>
            <span>{file.name}</span>
          </FileUpload.PreviewItem>
        ))}
      </FileUpload.PreviewList>
    </FileUpload.Root>
  );
}
```

### Upload with progress tracking

To show upload progress, track the upload state separately from file selection:

```jsx title="Upload with progress" "uploadProgress"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

export default function FileUploadWithProgress() {
  const [uploadProgress, setUploadProgress] = React.useState<Record<string, number>>({});
  const { files } = FileUpload.useFileUploadContext();

  const uploadFile = async (file: File) => {
    const xhr = new XMLHttpRequest();

    xhr.upload.addEventListener('progress', (e) => {
      if (e.lengthComputable) {
        const percentComplete = Math.round((e.loaded / e.total) * 100);
        setUploadProgress((prev) => ({
          ...prev,
          [file.name]: percentComplete,
        }));
      }
    });

    xhr.addEventListener('load', () => {
      setUploadProgress((prev) => ({
        ...prev,
        [file.name]: 100,
      }));
    });

    const formData = new FormData();
    formData.append('file', file);
    xhr.open('POST', '/api/upload');
    xhr.send(formData);
  };

  return (
    <FileUpload.Root>
      <FileUpload.Input />
      <FileUpload.Dropzone>Drop files here</FileUpload.Dropzone>

      {files.length > 0 && (
        <button onClick={() => files.forEach(uploadFile)}>
          Upload All Files
        </button>
      )}

      <FileUpload.PreviewList>
        {files.map((file) => (
          <FileUpload.PreviewItem key={file.id} file={file}>
            <div>
              <span>{file.name}</span>
              {uploadProgress[file.name] !== undefined && (
                <div>
                  <progress
                    value={uploadProgress[file.name]}
                    max="100"
                  />
                  <span>{uploadProgress[file.name]}%</span>
                </div>
              )}
            </div>
          </FileUpload.PreviewItem>
        ))}
      </FileUpload.PreviewList>
    </FileUpload.Root>
  );
}
```

### Upload with retry and cancel

Implement retry logic for failed uploads and allow users to cancel in-progress uploads:

```jsx title="Upload with retry and cancel" "AbortController"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

interface FileUploadState {
  progress: number;
  status: 'idle' | 'uploading' | 'success' | 'error' | 'cancelled';
  error?: string;
  retries: number;
}

export default function FileUploadWithRetry() {
  const { files, removeFile } = FileUpload.useFileUploadContext();
  const [uploadStates, setUploadStates] = React.useState<Record<string, FileUploadState>>({});
  const abortControllersRef = React.useRef<Record<string, AbortController>>({});

  const uploadFile = async (file: File, retryCount = 0) => {
    const maxRetries = 3;
    const fileKey = file.id;

    // Initialize upload state
    setUploadStates((prev) => ({
      ...prev,
      [fileKey]: {
        progress: 0,
        status: 'uploading',
        error: undefined,
        retries: retryCount,
      },
    }));

    try {
      const controller = new AbortController();
      abortControllersRef.current[fileKey] = controller;

      const xhr = new XMLHttpRequest();

      xhr.upload.addEventListener('progress', (e) => {
        if (e.lengthComputable) {
          const percentComplete = Math.round((e.loaded / e.total) * 100);
          setUploadStates((prev) => ({
            ...prev,
            [fileKey]: { ...prev[fileKey], progress: percentComplete },
          }));
        }
      });

      await new Promise<void>((resolve, reject) => {
        xhr.addEventListener('load', () => {
          if (xhr.status >= 200 && xhr.status < 300) {
            resolve();
          } else {
            reject(new Error(`Upload failed with status ${xhr.status}`));
          }
        });

        xhr.addEventListener('error', () => reject(new Error('Network error')));
        xhr.addEventListener('abort', () => reject(new Error('Upload cancelled')));

        const formData = new FormData();
        formData.append('file', file);
        xhr.open('POST', '/api/upload', true);
        xhr.send(formData);
      });

      setUploadStates((prev) => ({
        ...prev,
        [fileKey]: {
          progress: 100,
          status: 'success',
          retries: retryCount,
        },
      }));
    } catch (error) {
      const message = error instanceof Error ? error.message : 'Unknown error';

      // Retry logic
      if (retryCount < maxRetries && message !== 'Upload cancelled') {
        setUploadStates((prev) => ({
          ...prev,
          [fileKey]: {
            progress: 0,
            status: 'idle',
            error: `Failed, retrying... (${retryCount + 1}/${maxRetries})`,
            retries: retryCount,
          },
        }));

        // Retry after 2 seconds
        setTimeout(() => uploadFile(file, retryCount + 1), 2000);
      } else {
        setUploadStates((prev) => ({
          ...prev,
          [fileKey]: {
            progress: 0,
            status: 'error',
            error: message === 'Upload cancelled' ? 'Cancelled' : `Failed after ${maxRetries} retries`,
            retries: retryCount,
          },
        }));
      }
    }
  };

  const cancelUpload = (fileKey: string) => {
    abortControllersRef.current[fileKey]?.abort();
    setUploadStates((prev) => ({
      ...prev,
      [fileKey]: {
        ...prev[fileKey],
        status: 'cancelled',
        progress: prev[fileKey].progress,
        retries: prev[fileKey].retries,
      },
    }));
  };

  const retryUpload = (file: File) => {
    uploadFile(file, 0);
  };

  return (
    <FileUpload.Root>
      <FileUpload.Input />
      <FileUpload.Dropzone>Drop files here</FileUpload.Dropzone>

      {files.length > 0 && (
        <button onClick={() => files.forEach((file) => uploadFile(file))}>
          Upload All Files
        </button>
      )}

      <FileUpload.PreviewList>
        {files.map((file) => {
          const state = uploadStates[file.id] || { progress: 0, status: 'idle', retries: 0 };

          return (
            <FileUpload.PreviewItem key={file.id} file={file}>
              <div>
                <span>{file.name}</span>

                {state.status === 'uploading' && (
                  <div>
                    <progress value={state.progress} max="100" />
                    <span>{state.progress}%</span>
                  </div>
                )}

                {state.status === 'success' && <span style={{ color: 'green' }}>✓ Uploaded</span>}

                {state.status === 'error' && (
                  <div>
                    <span style={{ color: 'red' }}>✗ {state.error}</span>
                    <button onClick={() => retryUpload(file)}>Retry</button>
                  </div>
                )}

                {state.status === 'uploading' && (
                  <button onClick={() => cancelUpload(file.id)}>Cancel</button>
                )}
              </div>
            </FileUpload.PreviewItem>
          );
        })}
      </FileUpload.PreviewList>
    </FileUpload.Root>
  );
}
```

**Key patterns:**

- **Retry**: Automatically retry failed uploads (configurable max retries)
- **Cancel**: Use `AbortController` to cancel in-progress uploads
- **State tracking**: Track each file's upload status separately
- **Exponential backoff**: Wait before retrying (e.g., 2 seconds)
- **User feedback**: Show progress, errors, and retry options

### Upload with pause and resume

Implement pause/resume functionality for long-running uploads:

```jsx title="Upload with pause and resume"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

interface UploadState {
  status: 'idle' | 'uploading' | 'paused' | 'success' | 'error';
  progress: number;
  error?: string;
}

export default function FileUploadWithPause() {
  const { files } = FileUpload.useFileUploadContext();
  const [uploadStates, setUploadStates] = React.useState<Record<string, UploadState>>({});
  const xhrsRef = React.useRef<Record<string, XMLHttpRequest>>({});

  const uploadFile = async (file: File) => {
    const fileKey = file.id;

    setUploadStates((prev) => ({
      ...prev,
      [fileKey]: { status: 'uploading', progress: 0 },
    }));

    try {
      const xhr = new XMLHttpRequest();
      xhrsRef.current[fileKey] = xhr;

      xhr.upload.addEventListener('progress', (e) => {
        if (e.lengthComputable) {
          const percentComplete = Math.round((e.loaded / e.total) * 100);
          setUploadStates((prev) => {
            const current = prev[fileKey];
            // Only update progress if not paused
            if (current?.status !== 'paused') {
              return {
                ...prev,
                [fileKey]: { ...current, progress: percentComplete },
              };
            }
            return prev;
          });
        }
      });

      await new Promise<void>((resolve, reject) => {
        xhr.addEventListener('load', () => {
          if (xhr.status >= 200 && xhr.status < 300) {
            resolve();
          } else {
            reject(new Error(`Upload failed with status ${xhr.status}`));
          }
        });

        xhr.addEventListener('error', () => reject(new Error('Network error')));

        const formData = new FormData();
        formData.append('file', file);
        xhr.open('POST', '/api/upload');
        xhr.send(formData);
      });

      setUploadStates((prev) => ({
        ...prev,
        [fileKey]: { status: 'success', progress: 100 },
      }));
    } catch (error) {
      const message = error instanceof Error ? error.message : 'Unknown error';
      setUploadStates((prev) => ({
        ...prev,
        [fileKey]: { status: 'error', progress: prev[fileKey]?.progress || 0, error: message },
      }));
    }
  };

  const pauseUpload = (fileKey: string) => {
    const xhr = xhrsRef.current[fileKey];
    if (xhr) {
      xhr.abort();
      setUploadStates((prev) => ({
        ...prev,
        [fileKey]: { ...prev[fileKey], status: 'paused' },
      }));
    }
  };

  const resumeUpload = (file: File) => {
    setUploadStates((prev) => ({
      ...prev,
      [file.id]: { ...prev[file.id], status: 'uploading' },
    }));
    uploadFile(file);
  };

  return (
    <FileUpload.Root>
      <FileUpload.Input />
      <FileUpload.Dropzone>Drop files here</FileUpload.Dropzone>

      {files.length > 0 && (
        <button onClick={() => files.forEach(uploadFile)}>
          Upload All Files
        </button>
      )}

      <FileUpload.PreviewList>
        {files.map((file) => {
          const state = uploadStates[file.id] || { status: 'idle', progress: 0 };

          return (
            <FileUpload.PreviewItem key={file.id} file={file}>
              <div>
                <span>{file.name}</span>

                {state.status === 'uploading' && (
                  <div>
                    <progress value={state.progress} max="100" />
                    <span>{state.progress}%</span>
                  </div>
                )}

                {state.status === 'paused' && (
                  <div>
                    <span>Paused at {state.progress}%</span>
                    <button onClick={() => resumeUpload(file)}>Resume</button>
                  </div>
                )}

                {state.status === 'uploading' && (
                  <button onClick={() => pauseUpload(file.id)}>Pause</button>
                )}

                {state.status === 'success' && (
                  <span style={{ color: 'green' }}>✓ Completed</span>
                )}

                {state.status === 'error' && (
                  <span style={{ color: 'red' }}>✗ {state.error}</span>
                )}
              </div>
            </FileUpload.PreviewItem>
          );
        })}
      </FileUpload.PreviewList>
    </FileUpload.Root>
  );
}
```

**Note**: Complete pause/resume requires chunked uploads with server support (upload part by part). The example above shows the UI pattern; your server needs to support resuming from the last received byte.

### Form integration

Integrate FileUpload with HTML forms:

```jsx title="FileUpload in a form"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

export default function FileUploadForm() {
  const { files } = FileUpload.useFileUploadContext();
  const [formData, setFormData] = React.useState({ title: '' });

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();

    const data = new FormData();
    data.append('title', formData.title);
    files.forEach((file) => data.append('files', file));

    await fetch('/api/submit', { method: 'POST', body: data });
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        placeholder="Title"
        value={formData.title}
        onChange={(e) => setFormData({ title: e.target.value })}
      />

      <FileUpload.Root>
        <FileUpload.Input />
        <FileUpload.Dropzone>Drop files here</FileUpload.Dropzone>
        <FileUpload.Trigger>Select files</FileUpload.Trigger>
      </FileUpload.Root>

      <button type="submit">Submit</button>
    </form>
  );
}
```

## FAQ

### Why is there no built-in upload?

File Upload is **headless** — it handles the UI abstraction for file selection and validation, but not the upload mechanism. This gives you complete control to:

- Use any HTTP client (fetch, axios, React Query, etc.)
- Upload to any service (your server, S3, Cloudinary, etc.)
- Implement custom retry/pause/resume logic
- Track progress however you want

This design follows Base UI's philosophy of minimal, focused components.

### How do I integrate with my backend?

See the [Uploading Files](#uploading-files) section above. Use `fetch`, `axios`, or any HTTP client with the `onFilesChange` callback to send files when ready.

### Can I crop or resize images?

Image processing (cropping, resizing, filters) is outside FileUpload's scope. Consider using:

- [Sharp](https://sharp.pixelplumbing.com/) (Node.js server-side)
- [Canvas API](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) (client-side)
- [Konva](https://konvajs.org/) (image editor UI)

### Do I need to revoke preview URLs?

If you create your own previews with `URL.createObjectURL`, you should revoke them when a file is removed or when the component unmounts to avoid memory leaks.

File Upload automatically revokes the `file.preview` URLs it creates when files are removed or the component unmounts. If you create additional preview URLs, revoke them manually:

```jsx title="Preview cleanup"
React.useEffect(() => {
  return () => {
    files.forEach((file) => URL.revokeObjectURL(file.preview));
  };
}, [files]);
```

### How do I add drag-to-reorder for files?

Reordering isn't built-in, but you can implement it with the file state:

```jsx title="File reordering"
const [files, setFiles] = React.useState([]);

const moveFile = (fromIndex: number, toIndex: number) => {
  const newFiles = [...files];
  const [removed] = newFiles.splice(fromIndex, 1);
  newFiles.splice(toIndex, 0, removed);
  setFiles(newFiles);
};
```

### Can I validate file content, not just extension?

Currently, validation is limited to MIME type and extension matching. For deep file validation (magic numbers, actual format), validate on your server:

```jsx title="Server-side validation"
const handleUpload = async (file: File) => {
  const formData = new FormData();
  formData.append('file', file);

  const response = await fetch('/api/validate-upload', {
    method: 'POST',
    body: formData,
  });

  const result = await response.json();
  if (!result.valid) {
    // Handle invalid file
  }
};
```
