## Usage guidelines

- File Upload handles file selection and validation. You implement network upload logic separately.
- Use `FileUpload.Root` as the state container.
- Add `FileUpload.HiddenInput` inside `FileUpload.Root` to enable file selection.
- Use `FileUpload.Trigger` to collect files.
- Use `FileUpload.useFileUploadContext` to render selected files and actions such as remove.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { FileUpload } from '@base-ui/react/file-upload';

<FileUpload.Root>
  <FileUpload.HiddenInput />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>;
```

## Examples

### Basic setup

```jsx title="Basic file upload"
import { FileUpload } from '@base-ui/react/file-upload';

function SelectedFiles() {
  const { files, removeFile } = FileUpload.useFileUploadContext();

  if (files.length === 0) {
    return <p>No files selected.</p>;
  }

  return (
    <ul>
      {files.map((file) => (
        <li key={file.id}>
          {file.name}
          <button onClick={() => removeFile(file.id)}>Remove</button>
        </li>
      ))}
    </ul>
  );
}

export default function App() {
  return (
    <FileUpload.Root>
      <FileUpload.HiddenInput />
      <FileUpload.Trigger>Select files</FileUpload.Trigger>
      <SelectedFiles />
    </FileUpload.Root>
  );
}
```

### File validation

```jsx title="Validation props" "accept" "maxSize" "minSize" "maxFiles"
<FileUpload.Root
  accept="image/png, image/jpeg, .pdf"
  maxSize={10 * 1024 * 1024}
  minSize={1024}
  maxFiles={5}
  onFilesAdd={(acceptedFiles, fileRejections) => {
    fileRejections.forEach(({ file, reason, eventDetails }) => {
      console.log(`Rejected ${file.name}: ${reason}`, eventDetails.message);
    });
  }}
>
  <FileUpload.HiddenInput />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>
```

### Custom validation

```jsx title="Custom validator" "validator"
<FileUpload.Root
  validator={(file) => {
    if (file.name.includes('confidential')) {
      return 'Confidential files are not allowed';
    }
    return null;
  }}
>
  <FileUpload.HiddenInput />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>
```

### Handling file dialog cancellation

```jsx title="onCancel"
<FileUpload.Root onCancel={() => console.log('User canceled file selection')}>
  <FileUpload.HiddenInput />
  <FileUpload.Trigger>Select files</FileUpload.Trigger>
</FileUpload.Root>
```

## Accessibility

- Pair controls with a visible label.
- Keep trigger text descriptive.
- File Upload includes live region announcements for key file events.

```jsx title="Labeling with Field"
import { Field } from '@base-ui/react/field';
import { FileUpload } from '@base-ui/react/file-upload';

<Field.Root>
  <Field.Label>Profile image</Field.Label>
  <FileUpload.Root accept="image/*">
    <FileUpload.HiddenInput />
    <FileUpload.Trigger>Select image</FileUpload.Trigger>
  </FileUpload.Root>
</Field.Root>;
```

## Uploading files

File Upload does not upload files by itself. Use `FileUpload.useFileUploadContext` to read selected files, then send them with `fetch`, `axios`, or your upload client.

```jsx title="Upload selected files"
import * as React from 'react';
import { FileUpload } from '@base-ui/react/file-upload';

function Uploader() {
  const { files, clearFiles } = FileUpload.useFileUploadContext();

  const handleUpload = async () => {
    const formData = new FormData();
    files.forEach((file) => formData.append('files', file));

    await fetch('/api/upload', {
      method: 'POST',
      body: formData,
    });

    clearFiles();
  };

  return <button onClick={handleUpload}>Upload</button>;
}

export default function App() {
  return (
    <FileUpload.Root>
      <FileUpload.HiddenInput />
      <FileUpload.Trigger>Select files</FileUpload.Trigger>
      <Uploader />
    </FileUpload.Root>
  );
}
```
