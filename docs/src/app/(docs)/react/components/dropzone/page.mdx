## Usage guidelines

- Use `Dropzone` to handle drag-and-drop and keyboard/pointer activation.
- Add `Dropzone.HiddenInput` to support click-to-select as part of the same interaction surface.
- Use `onFilesDrop` for dropped files and `Dropzone.HiddenInput` `onChange` for selected files.
- **Form controls must have an accessible name**: Provide visible text in the dropzone, or set `aria-label`/`aria-labelledby` for icon-only UIs. See [Labeling a dropzone](#labeling-a-dropzone) and the [forms guide](/react/handbook/forms).
- Avoid placing interactive descendants such as buttons or links inside `Dropzone`. Place secondary actions next to the dropzone or use a separate trigger.
- **Built-in announcements**: `Dropzone` includes a live region that announces drag state transitions for screen reader users.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Dropzone } from '@base-ui/react/dropzone';

<Dropzone>
  <Dropzone.HiddenInput />
  Drop files here
</Dropzone>;
```

## Examples

### Dropzone with file input

```jsx title="Dropzone with file input"
import * as React from 'react';
import { Dropzone } from '@base-ui/react/dropzone';

export default function App() {
  const [files, setFiles] = React.useState([]);

  const appendFiles = React.useCallback((nextFiles) => {
    setFiles((prev) => [...prev, ...nextFiles]);
  }, []);

  return (
    <Dropzone onFilesDrop={(droppedFiles) => appendFiles(droppedFiles)}>
      <Dropzone.HiddenInput
        multiple
        onChange={(event) => {
          const selectedFiles = Array.from(event.currentTarget.files ?? []);
          if (selectedFiles.length > 0) {
            appendFiles(selectedFiles);
          }
          event.currentTarget.value = '';
        }}
      />
      Drop files here or click
    </Dropzone>
  );
}
```

### Labeling a dropzone

For icon-only designs, provide an explicit accessible name:

```tsx title="Icon-only dropzone"
import { Dropzone } from '@base-ui/react/dropzone';

<Dropzone aria-label="Upload files">
  <Dropzone.HiddenInput />
  <UploadIcon aria-hidden />
</Dropzone>;
```
