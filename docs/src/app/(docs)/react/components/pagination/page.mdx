## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Pagination } from '@base-ui/react/pagination';

<Pagination.Root count={10}>
  <Pagination.List>
    <Pagination.FirstButton />
    <Pagination.PrevButton />
    <Pagination.Pages />
    <Pagination.NextButton />
    <Pagination.LastButton />
  </Pagination.List>
</Pagination.Root>;
```
