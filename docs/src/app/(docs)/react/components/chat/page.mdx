## Anatomy

Chat is composed of several sub-components, each exported as its own namespace:

```jsx title="Anatomy"
import { Chat } from '@base-ui/react/chat';
import { ChatMessageList } from '@base-ui/react/chat-message-list';
import { ChatMessageGroup } from '@base-ui/react/chat-message-group';
import { ChatMessage } from '@base-ui/react/chat-message';
import { ChatComposer } from '@base-ui/react/chat-composer';
import { ChatConversationList } from '@base-ui/react/chat-conversation-list';
import { ChatConversation } from '@base-ui/react/chat-conversation';
import { ChatSuggestions } from '@base-ui/react/chat-suggestions';

<Chat.Root adapter={adapter}>
  <Chat.Layout>
    {/* Conversation sidebar (optional) */}
    <ChatConversationList.Root pane="conversations">
      <ChatConversationList.Item conversationId="…">
        <ChatConversationList.ItemContent>
          <ChatConversationList.Title />
          <ChatConversationList.Preview />
        </ChatConversationList.ItemContent>
      </ChatConversationList.Item>
    </ChatConversationList.Root>

    {/* Thread */}
    <ChatConversation.Root pane="thread">
      <ChatConversation.Header>
        <ChatConversation.Title />
      </ChatConversation.Header>

      <ChatMessageList.Root
        renderItem={({ id, index }) => (
          <ChatMessageGroup.Root messageId={id} index={index}>
            <ChatMessage.Root messageId={id}>
              <ChatMessage.Avatar />
              <ChatMessage.Content />
            </ChatMessage.Root>
          </ChatMessageGroup.Root>
        )}
      >
        <ChatMessageList.Viewport>
          <ChatMessageList.Content />
        </ChatMessageList.Viewport>
      </ChatMessageList.Root>

      <ChatSuggestions.Root suggestions={['…']} />

      <ChatComposer.Root>
        <ChatComposer.TextArea />
        <ChatComposer.Toolbar>
          <ChatComposer.SendButton />
        </ChatComposer.Toolbar>
      </ChatComposer.Root>
    </ChatConversation.Root>
  </Chat.Layout>
</Chat.Root>;
```

## Adapters

`Chat.Root` requires an `adapter` that connects it to a language model or messaging backend. Use `createEchoAdapter` for demos and prototyping:

```tsx
import { Chat, createEchoAdapter } from '@base-ui/react/chat';

const adapter = createEchoAdapter();

<Chat.Root adapter={adapter}>…</Chat.Root>;
```

For production, use `createAiSdkAdapter` with the [AI SDK](https://sdk.vercel.ai/):

```tsx
import { Chat, createAiSdkAdapter } from '@base-ui/react/chat';
import { openai } from '@ai-sdk/openai';

const adapter = createAiSdkAdapter({ model: openai('gpt-4o') });

<Chat.Root adapter={adapter}>…</Chat.Root>;
```

## Message rendering

`ChatMessageList.Root` requires a `renderItem` prop to render each message row. The function receives `{ id, index }` and should return a `ChatMessageGroup.Root` wrapping a `ChatMessage.Root`:

```tsx
<ChatMessageList.Root
  renderItem={({ id, index }) => (
    <ChatMessageGroup.Root messageId={id} index={index}>
      <ChatMessage.Root messageId={id}>
        <ChatMessage.Avatar />
        <ChatMessage.Content />
      </ChatMessage.Root>
    </ChatMessageGroup.Root>
  )}
>
  <ChatMessageList.Viewport>
    <ChatMessageList.Content />
  </ChatMessageList.Viewport>
</ChatMessageList.Root>
```

`ChatMessageGroup.Root` tracks consecutive messages from the same author. Each `ChatMessage.Root` that is not the first in a group receives `data-grouped`, which you can use to hide the avatar or compact spacing.

## Avatar

By default, `ChatMessage.Avatar` renders an `<img>` using the `avatarUrl` from the `members` configuration. To show a fallback (initials, icon) when the image fails to load, compose it with the Base UI [Avatar](/react/components/avatar) component. When `children` is provided, `ChatMessage.Avatar` renders those instead of the automatic `<img>`.

Access the author's `displayName` and `avatarUrl` via `ChatMessage.useMessageContext()` inside the `ChatMessage.Root` subtree:

```tsx
import { Avatar } from '@base-ui/react/avatar';

function MessageAvatar() {
  const { resolvedAuthor } = ChatMessage.useMessageContext();
  const initial = resolvedAuthor?.displayName?.[0]?.toUpperCase() ?? '';
  return (
    <ChatMessage.Avatar>
      <Avatar.Root>
        <Avatar.Image
          src={resolvedAuthor?.avatarUrl ?? ''}
          alt={resolvedAuthor?.displayName ?? ''}
        />
        <Avatar.Fallback>{initial}</Avatar.Fallback>
      </Avatar.Root>
    </ChatMessage.Avatar>
  );
}
```

Then use `<MessageAvatar />` inside your `renderItem` function in place of `<ChatMessage.Avatar />`.

## Styling

All parts expose data attributes for styling based on state:

| Component                 | Data attributes                                                    |
| :------------------------ | :----------------------------------------------------------------- |
| `ChatMessage.Root`        | `data-own-message`, `data-grouped`, `data-streaming`, `data-error` |
| `ChatMessage.Avatar`      | `data-show-avatar`, `data-grouped`, `data-own-message`             |
| `ChatMessageGroup.Root`   | `data-author-role`, `data-author-id`                               |
| `ChatComposer.Root`       | `data-has-value`                                                   |
| `ChatComposer.SendButton` | `data-disabled`, `data-loading`                                    |

```css
/* Style user vs assistant messages */
.message[data-own-message] .bubble {
  background: blue;
  color: white;
}

/* Remove avatar for grouped messages */
.avatar[data-grouped] {
  visibility: hidden;
}
```

## Suggestions

Display prompt suggestions before the conversation starts using `ChatSuggestions.Root`:

```tsx
<ChatSuggestions.Root
  suggestions={['What is Base UI?', 'Show me an example', 'How do I customize styles?']}
  autoSubmit
/>
```

Suggestions are hidden automatically once messages exist. Set `alwaysVisible` to keep them visible throughout the conversation.

## Two-pane layout

Use `Chat.Layout` with `ChatConversationList` and `ChatConversation` to build a two-pane chat interface with a conversation sidebar:

```tsx
<Chat.Root adapter={adapter} initialConversations={conversations}>
  <Chat.Layout>
    <ChatConversationList.Root pane="conversations">
      {conversationIds.map((id) => (
        <ChatConversationList.Item key={id} conversationId={id}>
          <ChatConversationList.ItemContent>
            <ChatConversationList.Title />
            <ChatConversationList.Preview />
          </ChatConversationList.ItemContent>
          <ChatConversationList.Timestamp />
          <ChatConversationList.UnreadBadge />
        </ChatConversationList.Item>
      ))}
    </ChatConversationList.Root>

    <ChatConversation.Root pane="thread">
      <ChatConversation.Header>
        <ChatConversation.HeaderInfo>
          <ChatConversation.Title />
          <ChatConversation.Subtitle />
        </ChatConversation.HeaderInfo>
      </ChatConversation.Header>

      <ChatMessageList.Root renderItem={…}>
        <ChatMessageList.Viewport>
          <ChatMessageList.Content />
        </ChatMessageList.Viewport>
      </ChatMessageList.Root>

      <ChatComposer.Root>
        <ChatComposer.TextArea />
        <ChatComposer.Toolbar>
          <ChatComposer.SendButton />
        </ChatComposer.Toolbar>
      </ChatComposer.Root>
    </ChatConversation.Root>
  </Chat.Layout>
</Chat.Root>
```
